# Keyboard shortcuts

All shortcuts at a glance. On Windows and Linux, <kbd>Ctrl</kbd> stands for <kbd>⌘</kbd> and <kbd>Alt</kbd> for <kbd>⌥</kbd>.

## Everywhere

| Shortcut | Effect |
| --- | --- |
| <kbd>⌘</kbd> <kbd>K</kbd> | Quick search |
| <kbd>⌘</kbd> <kbd>N</kbd> | New page |
| <kbd>Esc</kbd> | Close a dialog, menu or the search |

## In a document

| Shortcut | Effect |
| --- | --- |
| <kbd>/</kbd> | Block menu |
| <kbd>@</kbd> | Mention a page or person |
| <kbd>⌘</kbd> <kbd>B</kbd> / <kbd>I</kbd> / <kbd>U</kbd> | Bold, italic, underline |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>S</kbd> | Strikethrough |
| <kbd>⌘</kbd> <kbd>E</kbd> | Inline code |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>H</kbd> | Highlight |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>H</kbd> | Hide (spoiler) |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>M</kbd> | Comment on text |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>1</kbd>–<kbd>3</kbd> | Heading 1–3 |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>8</kbd> / <kbd>7</kbd> / <kbd>9</kbd> | Bulleted list, numbered list, task list |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>B</kbd> | Quote |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>C</kbd> | Code block |
| <kbd>Tab</kbd> / <kbd>⇧</kbd> <kbd>Tab</kbd> | Indent / outdent |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>↑</kbd> / <kbd>↓</kbd> | Move block up / down |
| <kbd>⇧</kbd> <kbd>Enter</kbd> | Line break within the same block |
| <kbd>⌘</kbd> <kbd>Z</kbd> / <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>Z</kbd> | Undo / redo |
| <kbd>⌘</kbd> <kbd>Enter</kbd> | Send a comment |

Markdown shortcuts such as `##`, `-`, `[]` or ` ``` ` are listed under [Documents and the editor](/docs/dokumente#markdown-shortcuts).

## Whiteboard

| Shortcut | Effect |
| --- | --- |
| <kbd>V</kbd> <kbd>H</kbd> <kbd>N</kbd> <kbd>T</kbd> <kbd>R</kbd> <kbd>L</kbd> <kbd>P</kbd> <kbd>F</kbd> <kbd>G</kbd> <kbd>C</kbd> | Select, hand, sticky note, text, shape, connector, pen, frame, table, comment |
| <kbd>⇧</kbd> <kbd>1</kbd> | Show everything |
| <kbd>⌘</kbd> <kbd>D</kbd> | Duplicate |
| <kbd>Del</kbd> | Delete |
| <kbd>⌘</kbd> <kbd>Z</kbd> / <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>Z</kbd> | Undo / redo |

## Calendar and timeline

| Shortcut | Effect |
| --- | --- |
| <kbd>⌥</kbd> <kbd>↑</kbd> / <kbd>↓</kbd> | Move an appointment by 15 minutes (with <kbd>⇧</kbd>: change the end) |
| <kbd>⌥</kbd> <kbd>←</kbd> / <kbd>→</kbd> | Move by one day |
| <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>←</kbd> / <kbd>→</kbd> | Timeline: change the end |
| <kbd>⌥</kbd> <kbd>Ctrl</kbd> <kbd>←</kbd> / <kbd>→</kbd> | Timeline: change the start |

## In this documentation

<kbd>/</kbd> jumps into the search, arrow keys choose a hit, <kbd>Enter</kbd> opens it.
